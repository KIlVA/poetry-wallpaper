# 生产模板

当前生产模板仅为 TYPOW_POEM（Poetry Wallpaper）。图文按红框统一左右各8%边距（x0.08/w0.84），三行y0.17/0.225/0.36，整体构图上移0.04（第三行贴近照片顶，行底距照片顶约0.0125），保留0.055行距和0.06em字距。诗句字号0.032是自适应上限，各行最多40个Unicode码点；署名字号上限0.012、最多24个码点，右缘对齐照片右缘留呼吸边（右对齐）。方图宽84%，按1024×1820基准换算1:1，保持原底边约0.89512，顶边约0.42251；裁块按旧照片框的相对位置同步缩放，署名底边与照片底边齐平（同一照片锚点表达式），右缘距照片右缘留0.028，右对齐。模板声明版式、输入上限和纹理配方，交由共享引擎渲染；旧 Grunge 模板已删除，历史设计记录保留。
