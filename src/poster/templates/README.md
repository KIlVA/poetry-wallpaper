# 生产模板

当前生产模板仅为 TYPOW_POEM（Poetry Wallpaper）。图文按红框统一左右各8%边距（x0.08/w0.84），三行y0.21/0.265/0.32，保留0.055行距和0.06em字距。诗句字号0.032是自适应上限，各行最多40个Unicode码点；署名字号上限0.012、最多24个码点，右侧内缩留气口。方图宽84%，按1024×1820基准换算1:1，保持原底边约0.93512，顶边约0.46251；裁块按旧照片框的相对位置同步缩放，署名距照片底留约画布高度2.8%的气口、右侧内缩不贴照片右边。模板声明版式、输入上限和纹理配方，交由共享引擎渲染。
