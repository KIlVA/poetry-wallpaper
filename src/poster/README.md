- [工作台、编辑导航与共享画布](components/README.md)

工作台采用局部深色语义 token，安全区仅由根消费，编辑区是非模态布局行。UI 的 Montserrat UI 500/600 与作品 Montserrat 400 字面隔离；字体准备完成后同一 Canvas 重绘。作品模板和 1290×2293 导出比例不变，尺寸说明位于作品外。

背景分类仅浏览，选择具体预设才改变作品。照片材质、固定背景与质感选项使用同一渲染器的 128×80 纯背景色样；无模拟照片、诗句或可见选项名称，不依赖字体加载。照片材质以纯渐变底作全幅输入，背景与质感无照片／文字图层。仅生成当前可见组选项并按配方缓存，不接收用户作品。色样四列、44px 高，保留辅助名称、焦点与选择状态；字体选项仍展示当前第一行短片段，质感选中态直接派生作品状态。

纯校样只隐藏编辑界面，画布与文件输入保持同一实例，返回编辑或 Escape 恢复触发按钮焦点。上传与下载即时防重入，错误在操作附近播报；失败保留原作品，卸载清理位图与下载 URL。PNG 经字体准备后生成 Blob，无照片也可下载。
