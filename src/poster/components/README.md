# 工作台组件

Poetry 工作台的布局、编辑导航、非模态编辑区与共享预览；作品渲染仍由引擎负责。照片组含无、玻璃分条、镜面模糊与积木材质，积木提供颗粒大小并反馈处理失败；文字组包含诗句／署名、署名颜色与全局同步字体选项；诗句每行40个Unicode码点、署名24个，带计数和超限提示，输入法合成结束后限长，切组与导出保留文字；风格组仅包含整版质感。
