# 共享海报渲染引擎

渲染入口接收模板、编辑状态和画布尺寸，预览与导出使用同一路径。照片效果、切片、色块和纹理属于共享能力，不随 Grunge 模板退役删除。文字可配置em字距，主画布逐条设置并将未配置项归零，照片内字母离屏画布同步；使用原生Canvas字距，测量、自适应字号与绘制保持一致。普通文字和诗句嵌图包含字形左右外伸量宽，必要时继续缩小，不在40%字号处停止；最多64轮，异常测量不继续绘制。模板字符上限用于输入，不静默改写已有内容；渲染仍适配完整文本。
